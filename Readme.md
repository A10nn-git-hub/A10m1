# UniversalGame3D / A10m1 Game Hub

Репозиторий кроссплатформенного 3D-проекта Unity (Windows Standalone x64 и Android ARM64 IL2CPP) с системой обновлений по воздуху (OTA) и автоматической рассылкой релизов через Telegram Bot API.

## Текущая версия
- **Сборка (Build Code):** #45
- **Версия (Version Name):** v1.45.0
- **Игровые режимы:**
  1. `GTA_OpenWorld_3D` — Открытый мир (транспорт, физика, мультиплеер, кастомизация).
  2. `Wind_3D` («Ветряные трубы») — Вертикальная шахта, восходящие и горизонтальные воздушные потоки, контактные терминалы-клапаны и батутная сетка.
  3. `Cube_3D` («Портальный куб») — Квантовые портальные врата, мгновенный перенос импульса и бесконечный вертикальный гравитационный цикл.
  4. `Tiles_3D` («Плитки») — 3 ряда по 20 островков, процедурная генерация безопасного маршрута, обрушение ложных плит и финишная лента.
  5. `Trials_3D` («Испытания») — «Импульсный сборщик» (архитектурный светофор со сканированием поля) и «Резонансный путь» (фазовые и пружинные платформы).

## Скрипт отправки `Send-TelegramRelease.ps1`

Для автоматической доставки новых сборок используется скрипт `Send-TelegramRelease.ps1`.
Скрипт автоматически:
1. Загружает Windows `.exe` напрямую через метод `sendDocument` Bot API.
2. Проверяет размер APK: если файл превышает лимит Telegram Bot API (50 MB), скрипт аккуратно нарезает его на части (`.part1`, `.part2`) с сохранением контрольных сумм и отправляет их документами в Telegram, прикрепляя также прямую ссылку на скачивание полного APK с GitHub CDN в 1 клик.
3. Доставляет файлы согласно строгим правилам:
   - Получателю `8092533566`: только APK.
   - Получателю `6278269178`: APK и EXE одновременно.

### Запуск вручную:
```powershell
pwsh -ExecutionPolicy Bypass -File .\Send-TelegramRelease.ps1 -Version "1.45.0" -Build 45
```
